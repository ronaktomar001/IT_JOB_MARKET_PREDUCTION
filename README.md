📊 IT Jobs Market Analysis

This project analyzes trends in the Information Technology job market using real-world job listing data. The goal is to uncover insights such as in-demand skills, salary trends, hiring patterns, and geographic job distribution.

The repository includes exploratory data analysis (EDA), visualizations, and a final interactive report to help job seekers, recruiters, and analysts better understand current IT hiring trends.

🚀 Project Overview

This project involves:

Data cleaning and preprocessing

Exploratory data analysis (EDA)

Skill and role frequency study

Salary range analysis

Visualization using Python libraries

Exporting results to an interactive HTML dashboard

The final generated interactive output file:
👉 IT_jobs_analysis.html
